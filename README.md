# Brazilian-E-Commerce-Public-Dataset-by-Olist
E-commerce data analysis using Python and Pandas.
## 📊 Project Brief

This project focuses on performing an in-depth analysis of an e-commerce dataset to uncover actionable insights related to sales performance, customer behavior, and product trends. The primary goal is to simulate real-world data analysis by working with raw datasets and transforming them into meaningful business insights.

The workflow begins with data loading and cleaning, where missing values, inconsistencies, and structural issues in the dataset are handled. This is followed by exploratory data analysis (EDA) to understand patterns, relationships, and distributions within the data.

Key areas of analysis include identifying overall sales trends over time, evaluating top-performing products and categories, analyzing customer purchasing behavior, and understanding the factors that influence revenue generation.

A unique aspect of this project is its structured, day-wise progress tracking approach. Each stage of the analysis is documented in separate folders (e.g., day1, day2), containing Jupyter notebooks along with brief summaries of the work completed. This approach ensures consistency, transparency, and a clear record of learning and improvements over time.

The project is implemented using Python, primarily leveraging libraries such as Pandas, and is developed in a notebook environment (Google Colab / Jupyter). The final outcome aims to demonstrate practical data analysis skills along with a well-documented workflow that reflects both technical understanding and problem-solving ability.
